# witty-parser-cli

Coffee → code → repeat. Mostly PostgreSQL these days.

拿来练手的小仓库

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/witty-parser-cli.git
cd witty-parser-cli
pip install -r requirements.txt
```
